The module is a flat, self-contained front-end demo composed of three files: `main.html` provides the page markup (header, banner section, wings SVG, tree diagram with research topic nodes, sound toggle), `main.sass` contains the SASS stylesheet that mirrors the HTML structure using BEM-style class names (`header-*`, `banner-*`, `tree-*`, `wings-*`), and `main.js` drives all motion via GSAP. The JS bootstraps on `window.load`, registers GSAP plugins (`Observer`, `SplitText`, `DrawSVGPlugin`, `MotionPathPlugin`, `ScrollTrigger`, `CustomEase`), defines named easing curves, and builds a master `tlAnimation` timeline bound to `ScrollTrigger` over the `<main>` element to orchestrate banner-to-tree transitions. A separate `treeAnimation()` timeline handles the reveal of the tree SVG branches via `drawSVG`, circle scaling, title reveals, and butterfly wing choreography. Hover interactions on `.tree-title` elements are driven per-node using `data-position` attributes to select matching branch paths and balls, animating them along `motionPath` curves. A small audio control toggles two looping timelines that animate `.sound-item` bars in sync with an embedded `<audio>` element.
