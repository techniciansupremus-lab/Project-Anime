Flat public directory acting as the web server root for a Vite/Next-style frontend. The PWA stack is defined by three core assets: `manifest.json` declares the app identity (name, theme colors, maskable icons) and registers `/favicon.png` as both 192x192 and 512x512 icons; `sw.js` implements a service worker with cache name `eetnet-pwa-v2` that pre-caches the shell (`/`, `/index.html`, `/manifest.json`, `/favicon.png`) on install, prunes old caches on activate, and uses a fetch-first-then-cache strategy with explicit bypass rules for `/assets/`, `/api/`, `/anilist-proxy`, external hosts (`anilist.co`, `streamindia`), and port 8080; `eetnet-config.json` exposes a runtime API base URL consumed at startup. Image assets under `home-carousel/` are bundled into the carousel UI, while `icons.svg`, `logo.png`, `logo-cat.png`, `naruto-og-naruto.gif`, and icon PNGs provide branding and social preview assets. There is no build logic here — these files are served verbatim by the hosting platform.
