The app is bootstrapped in `src/main.jsx`, which awaits `loadRuntimeConfig()` to resolve the backend API base (query param → Vercel serverless `/api/runtime-config` → static `public/eetnet-config.json` → build-time `VITE_API_BASE` → local dev) before mounting `App.jsx`. `App.jsx` is the central router and state hub: it holds global view/state for every feature (anime, drama, movies, manhwa, manga, hindi), drives client-side navigation via `window.history.pushState/replaceState` + `popstate`, persists session across reloads through `utils/sessionRestore.js`, and syncs watch history / watchlist between `localStorage` and Supabase on auth state changes. Each media type lives under `src/features/<type>/` with its own `api/` module (calling `runtimeConfig.apiUrl`) and `components/` views; shared presentation pieces (`Navbar`, `Sidebar`, `SectionSlider`, `AnimeCard`, `VideoPlayer`, `AuthModal`, `Webtoon*` views) live in `src/components/` and are imported by both feature views and the root layout. Cross-cutting concerns — device detection (`useDeviceType`), native Capacitor hooks (`nativeApp`), CBF recommendations (`cbf`), and storage helpers (`storage`) — are consumed uniformly by all features. Static assets and PWA config live under `public/` and are served as-is.
