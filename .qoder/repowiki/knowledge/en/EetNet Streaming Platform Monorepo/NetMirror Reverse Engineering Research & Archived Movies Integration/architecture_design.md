Two complementary sub-trees with no runtime coupling between them. `research on reverse engineering/NETMIRROR_RESEARCH.md` is the authoritative specification: it catalogs the rotating domain family (`net52.cc`, `net77.cc`, etc.), documents the single-POST `verify.php` auth bypass that issues a 72-hour `t_hash_t` cookie using a random UUID as `g-recaptcha-response`, enumerates all `/mobile/*` endpoints (`home`, `search.php`, `post.php`, `episodes.php`, `playlist.php`), explains HLS streaming via `nm-cdnN.top` with signed `in=` keys, and prescribes mounting routes into the existing Termux-hosted Express server alongside the AnimeRulz integration. `archive_movies_netmirror/` holds preserved implementation sketches intended to be imported into the main `server.js`: `server_netmirror_movies_routes.js` exports reusable helpers — `getNetmirrorToken()` (in-process token cache with expiry), `netmirrorApi(path, options)` (injects `t_hash_t` cookies, `ott` source prefix, `t=<unix>` cache-buster, retries once on `status:'n'`), plus TMDB metadata helpers (`getTmdbUrl`, `mapTmdbMovie`); `app_netmirror_movies_components.jsx` defines React UI components (`MovieCard`, `MovieRow`, `MovieHomeView`, `MovieWatchView`) styled for a Netflix-like catalog. Dependency direction is strictly one-way: the archived JS files depend only on Node stdlib (`axios`, `cheerio`, `crypto`) and are designed to be mounted into the host Express app without side effects on require.
