Requires the environment variable `NETMIRROR_BASE` (default `https://net52.cc`) before running the archived routes; when the NetMirror domain rotates, update this env var per the Telegram channel `t.me/netmirror_app`. Token refresh is lazy (on first request after expiry) but can also be warmed via a cron or `setInterval` every ~15 hours since the server grants a 72-hour `t_hash_t` cookie.
