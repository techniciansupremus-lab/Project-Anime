The workspace root is a single npm project whose `package.json` installs all dependencies once; the three runtime surfaces share that `node_modules`. The frontend SPA lives in `src/` (feature folders under `features/{anime,drama,manga,manhwa,movie}` plus shared `components/`) and is built by Vite (`npm run build`). The backend is a single-file Express app at `server.js` that registers every provider proxy route (`/api/m3u8-proxy`, `/api/ts-proxy`, `/api/subtitle-proxy`, `/api/img-proxy`, plus per-vertical routes) and re-exports through `api/index.js`; it also normalizes non-`/api/` URLs to `/api/...` for Vercel serverless. During development `vite.config.js` proxies `/api` calls to the local Express server on port 8080 so the browser can use relative paths without `VITE_API_BASE`. Production deploys both the static frontend and the Express server from the same artifact tree, with `vercel.json` rewriting `/api/(.*)` to `/api/index.js` and serving `index.html` as a catch-all. The Android shell in `android/` is configured via `capacitor.config.json` to load the built `dist/` web assets and expose native capabilities (splash screen, status bar, keyboard, filesystem, preferences). All three layers converge on Supabase (`@supabase/supabase-js`) for user state and on shared packages (`axios`, `cheerio`, `hls.js`, `@consumet/extensions`) consumed by both frontend feature APIs and backend proxy routes. Scratch scripts at the repo root (`scratch_*.cjs`, `tmdb_debug.mjs`, `proxy.py`) are ad-hoc research tools used to reverse-engineer content providers and integrate NetMirror/Movies/Dramas backends.
