The workspace root is a flat monorepo where three runtime surfaces share one `package.json` and one `node_modules`: `src/` is the React/Vite frontend (feature folders under `features/{anime,drama,manga,manhwa,movie}` plus shared `components/`), `server.js` boots the Express backend defined in `api/index.js`, and `android/` is the Capacitor wrapper configured via `capacitor.config.json`. During development Vite proxies `/api` calls to the local Express server on port 8080 (`vite.config.js`), so the frontend and backend are co-located and can be started together; in production the same build artifacts are served by the Express server or deployed to Vercel (`vercel.json`). All three layers converge on Supabase for user state (`src/supabaseClient.js`) and on shared npm packages (`axios`, `cheerio`, `hls.js`, `@consumet/extensions`) consumed by both the frontend feature APIs and the backend proxy routes. Scratch scripts at the repo root (`scratch_*.cjs`, `tmdb_debug.mjs`, `proxy.py`) serve as ad-hoc research tools for reverse-engineering content providers and NetMirror integration.
