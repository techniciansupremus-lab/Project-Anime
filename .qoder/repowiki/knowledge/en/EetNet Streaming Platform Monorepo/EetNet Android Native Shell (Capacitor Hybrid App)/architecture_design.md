Standard two-module Android Gradle project: `:app` is the installable APK whose only Java class (`MainActivity.java`) extends `com.getcapacitor.BridgeActivity`, delegating all UI to the embedded WebView; `:capacitor-cordova-android-plugins` is a placeholder module for Cordova plugin JARs served through a `flatDir` repository. The web application is bundled as static assets under `src/main/assets/public/` (a Vite-built SPA with `index.html`, service worker, and images) and loaded by Capacitor's configuration in `assets/capacitor.config.json`. Build configuration is split across root-level scripts (`build.gradle` declares AGP 8.13.0 and Google Services classpath), `variables.gradle` centralizes version numbers referenced via `rootProject.ext.*`, `app/build.gradle` defines SDK levels, build types, and dependencies, and `app/capacitor.build.gradle` — generated by `capacitor update` — pins Java 21 and pulls in Capacitor core plugins (`capacitor-app`, `capacitor-browser`, `capacitor-filesystem`, `capacitor-preferences`, `capacitor-splash-screen`, `capacitor-status-bar`). Dependency direction is strictly outward: the app depends on Capacitor core and the Cordova plugins module; no custom Kotlin/Java logic exists beyond the thin activity.
