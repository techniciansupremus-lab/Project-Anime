The module is a standard Android Gradle project with two modules: `:app` (the installable APK) and `:capacitor-cordova-android-plugins` (a placeholder for Cordova plugin JARs). The entry point is `MainActivity.java`, a one-line subclass of `com.getcapacitor.BridgeActivity`, so all UI logic lives in the web assets under `src/main/assets/public/` (a Vite-built SPA plus `index.html`, service worker, and static images). Capacitor configuration (`assets/capacitor.config.json`) declares the app ID, splash screen, status bar, keyboard behavior, and flags like `allowMixedContent`. Build configuration is split across root `build.gradle` (AGP 8.13.0, Google Services classpath), `variables.gradle` (shared version catalog), `app/build.gradle` (application manifest, min/target SDK, proguard, optional `google-services.json` plugin), and `app/capacitor.build.gradle` (generated by `capacitor update`; pins Java 21 and pulls in Capacitor core plugins: app, browser, filesystem, preferences, splash-screen, status-bar). Dependency direction is strictly outward: the app module depends on Capacitor core and the Cordova plugins module; no custom Java/Kotlin code exists beyond the thin activity.
