Run builds through the Gradle wrapper (`./gradlew assembleDebug / assembleRelease`). After any web-side changes, run `npx capacitor sync android` or `capacitor update` to regenerate `capacitor.build.gradle` and copy built assets into `assets/public/`. Push notifications require dropping a `google-services.json` file at `android/app/google-services.json` so the conditional plugin apply activates.
