Build through the Gradle wrapper (`./gradlew assembleDebug` / `assembleRelease`). After web-side changes, run `npx capacitor sync android` or `capacitor update` to regenerate `capacitor.build.gradle` and copy built assets into `assets/public/`. Push notifications require placing a `google-services.json` file at `android/app/google-services.json` so the conditional plugin apply activates.
