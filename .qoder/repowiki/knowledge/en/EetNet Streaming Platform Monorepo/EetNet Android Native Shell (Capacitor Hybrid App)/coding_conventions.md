- Native surface is kept minimal — the only Java class extends `BridgeActivity` and delegates all rendering to the embedded web view rather than implementing native UI.
- Build versions and dependency coordinates are centralized in root `variables.gradle` and consumed via `rootProject.ext.*` instead of being hard-coded in module scripts.
- Capacitor-generated build fragments (e.g., `capacitor.build.gradle`) are treated as read-only artifacts regenerated by `capacitor update` and must not be hand-edited.
- Optional features such as Google Play Services are gated behind runtime checks for the presence of `google-services.json` before applying the plugin.
