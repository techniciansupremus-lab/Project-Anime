- Native Android surface is kept minimal — the only Java class extends `BridgeActivity` and delegates all rendering to the embedded web view.
- Build versions and dependency coordinates are centralized in root-level `variables.gradle` and referenced via `rootProject.ext.*` rather than hard-coded in module scripts.
- Capacitor-generated build fragments (e.g., `capacitor.build.gradle`) are treated as read-only artifacts regenerated by `capacitor update` and must not be hand-edited.
