Flat directory rooted at `public/` with no build logic; files are served verbatim by the hosting platform. Three runtime artifacts define the PWA behavior: `manifest.json` declares app identity (`EetNet Anime, Drama & Webtoons`, standalone display, dark theme colors, maskable icons sourced from `/favicon.png`) and categories; `sw.js` registers a Service Worker using the Cache API with cache name `eetnet-pwa-v2`, pre-caching the shell (`/`, `/index.html`, `/manifest.json`, `/favicon.png`) on install, pruning stale caches on activate, and applying a fetch-first-then-cache strategy for same-origin GET requests while bypassing caching for `/assets/`, `/api/`, `/anilist-proxy`, external hosts (`anilist.co`, `streamindia`), and port 8080; navigation failures fall back to `/index.html`. `eetnet-config.json` exposes the backend API base URL consumed at application startup. All other files (`logo.png`, `logo-cat.png`, `icons.svg`, `icon-192.png`, `icon-512.png`, `favicon.svg`, `naruto-og-naruto.gif`, and `home-carousel/*`) are static branding and carousel media referenced via absolute paths from the site root.
