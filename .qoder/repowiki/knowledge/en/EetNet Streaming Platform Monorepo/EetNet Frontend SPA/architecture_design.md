Bootstrap in `src/main.jsx` awaits `loadRuntimeConfig()` to resolve the API base (query param → Vercel `/api/runtime-config` → `public/eetnet-config.json` → build-time `VITE_API_BASE`) before dynamically importing and mounting `App.jsx`. `App.jsx` is the central router and global state hub: it maintains per-feature view/state (anime, drama, movies, manhwa, manga, hindi), drives client-side navigation via `window.history.pushState/replaceState` + `popstate`, persists app session through `utils/sessionRestore.js`, and on `supabase.auth.onAuthStateChange` merges local `anistream_*` localStorage collections with Supabase tables (`watchlist`, `watch_history`). Each media domain lives under `src/features/<type>/` with its own `api/` module calling `runtimeConfig.apiUrl(path)` and feature-specific `components/` views; shared presentation pieces (`Navbar`, `Sidebar`, `SectionSlider`, `VideoPlayer`, `AuthModal`, `Webtoon*` views) live in `src/components/` and are imported by both feature views and the root layout. Cross-cutting utilities (`useDeviceType`, `nativeApp`, `cbf`, `storage`) are consumed uniformly by all features, while `public/` serves branding assets, PWA manifest/service worker and the runtime config file.
