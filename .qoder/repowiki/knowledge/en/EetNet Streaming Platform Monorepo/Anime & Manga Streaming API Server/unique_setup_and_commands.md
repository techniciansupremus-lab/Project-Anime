Run the Node server on `PORT` (default 8080) and start the Python KissKH relay on a separate `PROXY_PORT` (default 9090); both must be reachable behind ngrok/Cloudflare since the server derives its public base URL from `X-Forwarded-Proto`/`Host`. Frontend runtime config is resolved at request time from `process.env.API_BASE` / `VITE_API_BASE` / `PUBLIC_API_BASE` or a local `public/eetnet-config.json` file.
