Single-process Node.js server built on Express (`server.js`) that registers all HTTP routes under `/api/*` plus a Vercel-compatible rewriter that prefixes non-`/api/` paths. The `api/index.js` barrel re-exports the Express `app` instance for framework entry points, while `api/runtime-config.js` exposes a JSON endpoint that resolves the frontend's `API_BASE` from environment variables or a static `public/eetnet-config.json` file. Outbound provider access is split across three layers: (1) Consumet library clients (`@consumet/extensions` ANIME/META) for HiAnime and AniList metadata; (2) custom scrapers using Axios + Cheerio for AnimeKai and Jikan episode metadata; (3) a separate Python relay (`proxy.py`, standalone `http.server`) that forwards requests to KissKH on a distinct port to bypass host-header restrictions. In-memory `Map` caches with TTLs back episode lists, stream data, and catalog lookups. Media delivery goes through dedicated proxy endpoints — `/api/m3u8-proxy` rewrites master/sub-playlists and segment URLs to route through the same server, `/api/ts-proxy` streams `.ts` segments with Range forwarding, `/api/subtitle-proxy` serves VTT files, and `/api/img-proxy` hotlinks images with CORS bypass. Provider base URLs are externalized via environment variables (`KISSKH_BASE`, `ENCDEC_BASE`, `HIVETOONS_BASE`, `ANIMERULZ_*`) so the same binary can target different deployments.
