Two sub-trees serve complementary roles. `research on reverse engineering/NETMIRROR_RESEARCH.md` is the authoritative technical dossier: it catalogs NetMirror's rotating domain family (`net52.cc`, `net77.cc`, etc.), documents the one-request `verify.php` auth bypass (random UUID as captcha), enumerates all `/mobile/*` endpoints (`home`, `search.php`, `post.php`, `episodes.php`, `playlist.php`), explains HLS streaming via `nm-cdnN.top` with signed `in=` keys, and prescribes how to wire routes into the existing Termux-hosted Express server alongside the AnimeRulz integration. `archive_movies_netmirror/` holds preserved implementation sketches: `server_netmirror_movies_routes.js` exports reusable token caching (`getNetmirrorToken` with in-process expiry), a generic `netmirrorApi` helper that injects `t_hash_t` cookies and retries on `status:'n'`, plus TMDB helpers for metadata; `app_netmirror_movies_components.jsx` defines React UI components (`MovieCard`, `MovieRow`, `MovieHomeView`, `MovieWatchView`) styled for a Netflix-like catalog. Dependency direction is one-way — the archived JS files depend only on Node stdlib (`axios`, `cheerio`, `crypto`) and are intended to be mounted into the main `server.js` Express app.
